# 🏦 Bank Marketing Website (Bankist)

**Bank Marketing Website (Bankist)** is a modern, interactive landing page for a digital bank. The project focuses on building a clean UI with advanced JavaScript interactions such as smooth scrolling, tabbed components, lazy loading images, sliders, and modal windows.

This project is mainly built to practice **DOM manipulation, events, Intersection Observer API, and UI effects** using vanilla JavaScript.

---

## 🚀 Features

- Modal window for opening an account
- Smooth scrolling navigation
- Page navigation using event delegation
- Tabbed component for operations section
- Menu fade animation on hover
- Sticky navigation bar
- Reveal sections on scroll
- Lazy loading images for performance
- Slider / carousel with dots and arrows
- Keyboard navigation for slider

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla JS)
